# M5 环境感知与数据采集 · 课程大纲

> **双通信架构**：支持 **4G 蜂窝直连版（国内主流）** 与 **LoRaWAN 广域免布线版（国际通用）**。
> **能力分级**：L1 展示层（数据监视与架构认知）→ L2 顾问层（硬件接线与告警编排）→ L3 设计层（API 对接与本地自动化）。

## 一、培训目标

完成本课程培训后，学员与团队将具备以下能力：

- **工业传感器接线与调试**：掌握土壤、农业气象及环境温湿度等 RS485 工业传感器的引脚定义、电源分配与差分接线规范。
- **协议配置与通信组网**：掌握 Modbus RTU 寄存器配置，完成 4G 数据采集器（或 LoRaWAN 网关）的快速入网与设备绑定。
- **云端数据看板与告警策略**：熟练在 SenseCraft Data 平台中配置多条件阈值告警、趋势统计与报表导出。
- **API 数据集成与边缘控制（L3）**：掌握调用 SenseCAP Open API 获取环境时序数据，并在 reComputer 边缘端使用 Node-RED 实现本地闭环控制。

### 模块一：环境感知网络架构与数据监视（L1 展示层）

**目标**：理解环境监测系统的数据全生命周期链路（感知 → 采集传输 → 云端解析 → 业务呈现），掌握平台数据监视与报表操作。

**实操与演示内容**：

1. **物联网感知网络架构解析**
   - **4G 直连架构**：RS485 传感器 ──(Modbus RTU)──> 4G 采集器 ──(4G 蜂窝)──> SenseCraft Data 云平台。
   - **LoRaWAN 架构**：LoRaWAN 无线节点 ──(LoRa)──> 户外网关 ──(以太网/Wi-Fi；部分区域版本支持 4G)──> 云平台 ──(API)──> 边缘计算主机。
2. **传感器测量原理与典型场景**
   - 土壤水分、温度与电导率（EC）测量原理及墒情监测。
   - 七合一微型气象站（超声波风速风向、雷达雨量、光照、温湿压与总辐射）构造。
   - 农业多要素传感与叶面温湿度探头现场部署要点。
3. **SenseCraft Data 平台数据监控**
   - 网页端控制台：设备管理、实时数据卡片、历史趋势折线图与空间地理点位标绘。
   - 移动端 SenseCraft App：扫码快速绑定设备并查看设备状态与实时数据。
   - 数据报表：按小时/天/月聚合数据导出（CSV/Excel 格式导出与历史归档）。

**阶段交付**：每组完成多节点环境数据的实时监视，掌握平台数据筛选、报表导出与移动端查看操作。

**能力收获**：

- 理解 4G 与 LoRaWAN 两种通信方案的技术特性与选型依据
- 掌握常用农业、环保与气象传感器的指标含义
- 熟练使用 SenseCraft Data 平台进行日常数据监视与报表导出

### 模块二：传感器接线、Modbus 配置与规则告警（L2 顾问层）

**目标**：掌握 RS485 硬件接线、Modbus RTU 寄存器配置、采集器参数调优以及多条件告警策略配置。

**实战内容**：

1. **RS485 传感器接线实操（以 4G 版为例）**
   - 航空插头引脚定义（VCC、GND、RS485-A、RS485-B）。
   - 传感器电源供电匹配（5V/12V DC）。
   - 多传感器并联（RS485 分线器）与从机地址（Slave ID）防冲突设置。
2. **数据采集器配置与平台绑定**
   - 采集器与传感器 Modbus 寄存器映射表配置（起始地址、读取长度、数据类型解析）。
   - 设置数据采样间隔（Sampling Interval）与数据上传周期（Upload Interval）。
   - 在 SenseCraft Data 平台中完成设备 EUI 与 Key 绑定与通道命名。
3. **多级业务告警规则配置**
   - **阈值告警**：设定上下限绝对阈值（例如：土壤温度 < 5°C 霜冻预警、环境温度 > 35°C 高温通风预警）。
   - **突变与趋势告警**：设定单位时间内突变速率异常。
   - **设备运行状态告警**：采集器离线、传感器掉线与电池电量过低告警。
   - **通知渠道配置**：SenseCraft App 消息中心告警推送（支持 App 推送、邮件通知与 Webhook 渠道联动）。

**阶段交付**：每组独立完成一套包含 2 种以上传感器的物理接线、从机参数配置与 3 种业务场景的告警策略测试。

**能力收获**：

- 掌握 Modbus RTU 工业总线与标准传感器的接线和排障能力
- 熟练配置多通道数据采集器与云平台数据解析通道
- 具备独立设计和部署场景化告警响应策略的能力

### 模块三：API 数据集成与本地边缘自动化（L3 设计层）

**目标**：掌握 SenseCAP Open API 调用规范，使用 reComputer R1025 + Node-RED 实现局域网离线自动化控制与第三方平台对接。

**实操内容**：

1. **SenseCAP Open API 调用（SenseCraft Data 平台 HTTP API）**
   - 在 SenseCraft Data 平台「Security / Access API keys」中创建 Access ID 与 Access Key，采用 HTTP Basic Auth 鉴权（`https://sensecap.seeed.cc/openapi`）。
   - 编写 HTTP 请求获取最新遥测数据（list_telemetry_data）、历史时序数据与设备在线状态。
   - JSON 报文字段解析与数据清洗（响应码 `code=0` 表示成功，API 配额以响应头返回）。
2. **reComputer R1025 本地自动化编排**
   - 使用官方安装脚本在 reComputer R1025 上安装并启动 Node-RED（非出厂预装），访问 `http://[设备IP]:1880` 进入可视化编排环境。
   - 编写自动化流：定时轮询 / HTTP 请求拉取云端数据，判断环境阈值。
   - 本地控制逻辑开发：经 RS485 通道下发控制指令（如触发继电器模块或向工业控制器下发开启动作，如土壤干旱自动开启灌溉水阀）。
3. **第三方时序数据库与 Grafana 看板对接**（基于 Open API 数据流拉取，构建自定义工业监控大屏）
   - 将环境感知数据写入 InfluxDB 时序数据库。
   - 导入 Grafana 仪表盘模板，配置多区域环境对比大屏。

**阶段交付**：每组交付一套基于 Node-RED 的环境阈值联动控制流与一组 Grafana 监控大屏。

**能力收获**：

- 掌握云端物联网平台的 REST API 对接与数据提取能力
- 能够使用 Node-RED 编排复杂的本地边缘控制与时序逻辑
- 具备将传感器数据接入企业既有 ERP、MES 或私有化大屏系统的交付能力

## 四、风险与预期管理

### 环境与采集须知

- 传感器的测量精度受安装深度、土壤紧实度、电极表面洁净度等物理环境影响，需定期维护与校准。
- 4G 方案依赖现场蜂窝信号强度，地下室或深山需外接高增益天线；LoRaWAN 需确保网关与节点之间的视距遮挡评估。
- 数据采集存在传输延迟与定时周期（通常为分钟级），不适合高频闭环伺服控制。

### 明确不交付范围

- 不包含大面积土木施工与高空防雷工程实施。
- 不承诺由于极端自然灾害（淹没、雷击）导致的传感器硬件不可抗力损坏免责。
- 不包含对未开放协议的第三方老旧传感器的协议破解服务。
