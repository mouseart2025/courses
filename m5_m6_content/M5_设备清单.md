## 七、部署要点

1. **4G 网络覆盖**：4G 版需确认现场蜂窝信号强度，地下室或深山场景需外接高增益天线；每台采集器需插入有效物联网流量 SIM 卡。
2. **LoRaWAN 视距评估**：部署前评估网关与节点之间的视距遮挡，野外长期节点需配套太阳能板与高低温环境电池。
3. **RS485 总线规范**：确认航空插头引脚定义（VCC、GND、RS485-A、RS485-B），多传感器并联时通过分线器扩展，并设置唯一从机地址防止冲突。
4. **供电匹配**：传感器供电要求各异（5V/12V/24V DC），需与采集器总线输出匹配，避免过压损坏或欠压读数异常。
5. **采样与上传周期**：环境传感采样周期通常为 1–60 分钟（取决于业务设定），属于低频物联监测，不适合毫秒级闭环控制。
6. **传感器维护**：土壤、叶面与气象传感器精度受安装深度、电极洁净度、土壤紧实度等物理环境影响，需定期维护与校准。
7. **API 对接**：L3 调用 SenseCAP Open API 时，通过 `Security / Access API keys` 创建 Access ID 与 Access Key，采用 HTTP Basic Auth 鉴权。
8. **本地自动化**：reComputer R1025 上的 Node-RED 需通过官方一键安装脚本部署，访问 `http://[设备IP]:1880` 进行本地自动化编排。
