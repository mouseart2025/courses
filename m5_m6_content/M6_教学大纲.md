# M6 机器人控制与具身智能 · 课程大纲

> **能力分级**：L1 展示层（体验）→ L2 顾问层（实战）→ L3 设计层（交付）。
> **模块属性**：独立模块，无先修课程要求；各级所需学员基础见 M6.0 课程卡片速览表。
> **核心路径**：L1 选型认知与开箱上手（展示层）→ L2 场景剖析与多模态编排（顾问层）→ L3 空间抓取闭环与具身智能前瞻（设计层）。

## 一、培训目标

完成本课程培训后，学员与团队将具备以下能力：

- **机械臂选型与安全操作**：理解工业机械臂形态与商业选型权衡，掌握工作空间安全规范、急停使用与开箱遥操首验。
- **3D 场景认知与动作编排**：理解为什么复杂场景必须使用 6 轴机械臂，掌握 SenseCraft 动作流程编排与工位视觉数据采集/事件触发联动。
- **确定性 3D 空间抓取开发（L3.1）**：使用 RGB-D 深度相机获取目标 3D 坐标，利用 Python 工具库（Pinocchio）自动换算电机角度，通过 Motorbridge 驱动真机完成精准抓取。
- **具身智能与仿真前沿视野（L3.2）**：掌握遥操动作数据采集流程，理解具身大模型（VLA）与数字孪生仿真（Isaac Sim）的核心概念。

## 二、教学模块

### 模块〇：课前准备（讲师与助教）

> 培训开始前完成环境准备，对照 [M6.2 培训设备清单](M6.2 培训设备清单.md) 逐项清点台架物料，保障现场实操顺利进行。学员无需参与。

- **硬件台架清点**：按 [M6.2 培训设备清单](M6.2 培训设备清单.md) 确认 reBot DevArm B601-RS 机械臂、Master Arm 主控臂、Super J4012 主机、工作台 G 夹、独立硬件急停按钮与接线附件齐全。
- **机械臂物理固定与上电自检**：使用 G 夹将机械臂稳固夹持于实验台，完成上电与零点校准预演。
- **安全隔离区布置**：连接硬件急停常闭回路并测试硬切动力电；布置机械臂工作空间物理隔离区（警示胶带与防护围栏）。
- **控制中枢与网络预置**：Super J4012 主机部署 SenseCraft Robotics 控制台与 Pinocchio/Motorbridge 运行环境；完成各工位局域网配置。
- **视觉采集套件与光控箱就绪**：展开机械臂数据采集光控箱（100094392）并调节光源；安装双机位摄像头支架（100006505）并接入 ET-S231 广角 USB 摄像头（100035502）；可选 RGB-D 深度相机预置调试。

### 模块一：选型认知、安全规范与开箱上手（L1 展示层 · 体验 · 1 天）

**目标**：建立商业选型认知与现场安全底线，使用 SenseCraft 平台零代码完成语音与遥操初体验。

**实操与演示内容**：

1. **机械臂选型与商业取舍**：
   - 常见机械臂形态：直角坐标滑台、SCARA（四轴）、Delta（并联蜘蛛手）与六轴关节机械臂。
   - 商业选型权衡：在速度、精度、负载、成本与安全性之间的平衡取舍；为什么六轴机械臂是通用首选。
2. **实训安全第一课**：
   - 机械臂安全边界：划定物理工作空间与警示区域，禁止人体部位伸入运动包络区。
   - 硬件急停按钮：物理断电原理与演练（兜底安全保障）。
   - 防碰撞与慢速运行：遇到阻碍时的停机保护机制，规范开机与关机流程，落实设备急停与安全复位规程。
3. **开箱与 SenseCraft 极速上手**：
   - 认识 Seeed reBot Arm B601 机械臂各关节结构与接口。
   - 浏览器直接访问 [SenseCraft Robotics](https://sensecraft.seeed.cc/en/robotics) 控制台，免装复杂软件，完成设备连接与基础点动控制。
4. **遥操与语音抓取初体验**：
   - **主从臂遥操**：用主臂引导从臂同步跟随运动，直观体验机械臂的动作镜像复制与轨迹录制。
   - **语音指令控制**：配合麦克风（reSpeaker），直接说一句话触发机械臂完成预设夹取动作。

**阶段交付**：每组独立完成 1 次设备安全检查，并在平台通过语音指令成功触发一次夹取动作。

**能力收获**：

- 理解工业机械臂分类与商业选型逻辑
- 掌握机械臂物理安全规范与急停操作规程
- 掌握 SenseCraft 平台的开箱连接、主从遥操与语音指令控制

### 模块二：场景剖析、空间直觉与多模态编排（L2 顾问层 · 实战 · 2–3 天）

**目标**：讲清机械臂与 3D 场景的匹配价值，掌握多动作流程编排与工位视觉事件触发联动。

**实操内容**：

1. **机械臂落地场景与节拍核算**（约 0.5 天）：
   - 机械臂适合干什么：轻量分拣、工位上下料、展位互动、定点拍照巡检。
   - 什么时候**不用**机械臂：高速量产流水线（>1 件/秒）、超重负载搬运的边界认知。
   - 工序节拍与产能估算：如何根据单次抓取与复位时间评估实际方案可行性。
2. **为什么必须是「3D 空间」？**（约 0.5 天）：
   - 气缸/传送带只能在 2D 平面移动，机械臂不仅管“物体在哪里 (X, Y, Z)”，还能调整“什么倾角去夹（旋转姿态）”。
   - 空间直觉：不用算数学公式，在 3D 界面中直观理解机械臂的“伸展极限”与“卡死死区（手肘伸直转不动的情况）”。
3. **动作编排与安全确认机制**（约 0.5 天）：
   - 在 SenseCraft 平台中把多个点位串联成一条完整的作业流程（移动 → 张开爪子 → 下降 → 夹紧 → 抬起 → 放置）。
   - 引入「生成 → 3D 预览 → 人工确认 → 真机执行」确认机制，防止误操作撞机。
4. **工位视觉数据采集与事件联动实操（SenseCraft 光控实验箱）**（约 1 天）：
   - 结构化实验环境构建：在机械臂数据采集光控箱中设置恒定光照与标定工作区，消除环境杂光对识别的干扰。
   - 视觉感知的工程角色：通过架设在支架上的 ET-S231 USB 摄像头采集工位图像，检测工件到位情况，作为机械臂自动化作业的“事件触发器”。
   - 搭建联动流程：工位相机检测到物料进入作业区 → 触发抓取工序 → 机械臂执行预设编排轨迹与分类放置。
   - 认知边界（承上启下）：理解 2D 图像仅能在结构化恒定光照环境中提供状态触发；若物料三维空间位姿随机或高度不一，固定轨迹无法自适应，由此引出 L3 深度相机与空间运动学需求。
   - 分组搭建微场景系统：工位物料推送分拣、展位迎宾互动或定点视觉检测巡检（三选一）。

**阶段交付**：每组搭建并跑通 1 套由相机识别或传感器触发的微场景作业系统，实现连续 3 次稳定运行。

**能力收获**：

- 能独立向客户阐述 3D 场景为什么需要六轴机械臂及其选型边界
- 掌握 SenseCraft 多动作流程编排与安全确认机制配置
- 掌握基于工位视觉的事件触发与微场景联调交付

### 模块三：3D 空间抓取闭环与具身智能前瞻（L3 设计层 · 交付 · 3–5 天）

**目标**：通过深度相机打通“真正 3D 空间抓取”的确定性工程底座，并拓宽具身大模型与仿真前沿视野。

> 本模块分为「确定性工程交付（必修）」与「具身智能与前沿探索（进阶拓展）」两部分。

#### 第一部分：确定性工程交付（实打实落地 · 必修 2–3 天）

1. **深度相机 3D 定位与坐标对齐**（约 0.5 天）：
   - 单目 vs 深度相机：为什么任意位置抓取必须测距离（$Z$ 轴深度）。
   - 使用深度相机（RGB-D）直接读取物体在空间中的三维物理坐标 (X, Y, Z)。
   - 快速“手眼对齐”：把相机坐标系测出的点位换算成机械臂基座坐标系点位。
2. **坐标到电机角度的自动换算（Pinocchio 逆运动学求解）**（约 1 天）：
   - 不推导运动学数学公式，使用 Python 调用工具库（Pinocchio）。
   - 输入目标三维空间坐标 → 工具自动计算 6 个电机该转动多少度。
   - 异常处理：目标位置超出工作范围或解算失败时，编写异常报警与安全退回逻辑。
3. **真机驱动与端到端抓取闭环（Motorbridge SDK）**（约 1 天）：
   - 编写 Python 脚本调用 Motorbridge SDK 驱动机械臂平滑运动与控制夹爪。
   - 整合全流程闭环：**深度相机检测目标 3D 坐标 → Python 自动换算电机角度 → 驱动机械臂前往夹取**。

**阶段交付（确定性）**：交付 1 套完整 Python 工程源码；物料摆放在工作台任意有效位置，机械臂系统能自动识别 3D 坐标并完成准确夹取。

#### 第二部分：具身智能与前沿探索（进阶视野 · 选修/拓展 1–2 天）

1. **教机械臂学动作（遥操数据采集）**（约 0.5 天）：
   - 现代具身智能大模型的数据采集逻辑。
   - 结合数据采集光控箱与双机位摄像头支架（前视/俯视机位），使用主从臂遥操教机械臂完成复杂动作，录制包含关节角度与视觉画面的 LeRobot 标准动作数据集。
2. **具身大模型 (VLA) 与虚拟仿真初探**（约 0.5 天）：
   - **看图说话做动作（VLA 模型）**：了解输入文本提示词与图像直接输出动作的前沿架构。
   - **数字孪生仿真（Isaac Sim）**：在仿真环境中加载机械臂 3D 资产，观察虚拟物理碰撞与仿真控制流程，理解“先仿真后真机”的开发思路。

**阶段交付（前沿探索）**：产出 1 份标准格式的遥操动作数据集，并在仿真环境中成功运行 1 次虚拟机械臂抓取演示。

## 四、风险与预期管理

### 安全与现场须知

- 机械臂为带动力机构，实操过程中必须严格遵守安全规程，禁止将身体部位伸入机械臂运动包络区。
- 本大纲中的实操步骤、时长、性能指标与安全机制均按标准工程规范设计，正式授课前讲师须按台架规范逐项复核并完成预演。

### 交付与指标预期

- 视觉抓取成功率受光照条件、物体材质反光及摆放姿态影响，验收指标以现场实测记录为准。

### 明确不交付范围

- 不承诺达到高频重载工业机器人（节拍 > 1 件/秒）性能指标。
- 不包含微米级精密装配（如精密销孔插拔）与复杂柔性异形物料抓取。
- 不提供工业级安全认证背书（如 ISO 10218 / TS 15066）。
