# M1 设备互联与智能管控 · 课程大纲

> **设备互联与智能管控** × 企业培训实施指南

**课程定位：** 掌握基于 Home Assistant 与轻量硬件的低成本改造方案，在保留既有电气与工业设备的前提下，实现设备接入、能耗看板搭建与跨协议场景联动。

## 一、培训目标

完成本课程培训后，学员与团队将具备以下能力：

- **多协议集成能力**：掌握将 Wi-Fi、Zigbee 及 Modbus/RS485 等多协议设备接入统一管理平台的方法。
- **能耗监测与可视化**：实现单相/三相电表的数据采集与实时能耗监控仪表盘搭建。
- **本地自动化编排**：掌握基于 YAML 与 Node-RED 编排跨设备联动策略的工程方法。
- **系统安全与运维保障**：掌握局域网私有化部署、数据备份与灾难恢复流程，明确非关键系统与安全关键系统的工程边界。

## 二、教学模块

### 模块〇：课前准备（讲师与助教）

> 培训开始前完成软硬件与环境预检，对照 [M1.2 培训设备清单](M1.2 培训设备清单.md) 逐项清点，保障现场实操顺利进行。

- **硬件台架清点**：按 [M1.2 培训设备清单](M1.2 培训设备清单.md) 确认各工位工业网关、XIAO ESP32-C6、RS485 扩展板、DDSU666 智能电表、XY-MD02 变送器与电源线材齐全。
- **网络环境配置**：部署现场独立局域网 Wi-Fi 路由器，分配静态 IP 地址段与隔离策略。
- **网关固件预置**：完成工业边缘网关系统镜像预置与 Home Assistant 基础服务启动检查。
- **教学资料准备**：下发 ESPHome 示例代码与 YAML 配置模版，明确强电回路接线安全规程。

### 模块一：平台初识与基础设备接入（L1 展示层）

**目标**：掌握 Home Assistant 核心架构（实体 Entity、服务 Service、状态 State），完成基础传感器与常用智能硬件的快速接入与控制。

**实操与演示内容**：

1. **Home Assistant 系统架构与基础概念**
   - 核心概念解析：实体（Entity）、服务（Service）、状态（State）与自动化（Automation）
   - Lovelace 仪表盘基础配置与卡片布局
2. **消费级智能硬件接入**
   - 演示标准 Wi-Fi / Zigbee 智能插座与照明设备接入流程
   - 体验设备状态同步与手动控制
3. **微控制器节点实操（XIAO ESP32-C5 + Grove）**
   - 使用 ESPHome 编写基础温湿度采集配置
   - 固件在线编译与烧录（ESPHome Web / Serial）
   - 设备在 HA 中的自动发现与实体映射
4. **HA Energy 能耗看板初识**
   - 了解能源看板的配置结构与数据流向

**阶段交付**：每组独立完成 1 套 XIAO ESP32 传感器节点的上线与仪表盘监控卡片配置。

**能力收获**：

- 理解 Home Assistant 基础架构与核心概念
- 掌握 ESPHome 固件配置与微控制器传感器接入流程
- 能独立在 Lovelace 仪表盘中配置卡片并进行状态监控

### 模块二：工业总线对接与场景联动（L2 顾问层）

**目标**：掌握基于 ESPHome 对接 RS485/Modbus 工业设备与电表的方法，完成能耗看板搭建与多条件自动化联动。

**实操内容**：

1. **Modbus RTU 协议与硬件接线**
   - RS485 差分总线接线规范（A/B 线序、终端电阻匹配）
   - 波特率、数据位、校验位与从机地址（Slave ID）配置
   - 寄存器类型（Holding Register / Input Register）与数据解析
2. **工业传感器与电表接入实操**
   - 使用 XIAO RS485 扩展板读取 XY-MD02 工业温湿度变送器
   - 接入导轨式单相电表（DDSU666），读取电压、电流、功率与累计电量
3. **能源监控看板搭建**
   - 配置 HA Energy 模块，绑定电表累计电量实体
   - 实现实时用电功率曲线与分时能耗统计
4. **场景自动化策略配置**
   - 编写多条件联动规则（例如：环境温度超限启动风扇、光照低于阈值开灯、非工作时间异常功耗告警）

**阶段交付**：每组完成 1 个 Modbus 设备/电表接入、1 个实时能耗看板搭建，以及至少 2 套自动化联动规则配置。

**能力收获**：

- 掌握 Modbus RTU 工业协议的接线、调试与 YAML 寄存器配置
- 独立搭建完整的能耗计量与监控看板
- 掌握多条件自动化编排与异常告警配置

### 模块三：业务集成与系统运维（L3 设计层）

**目标**：掌握跨系统数据对接、Node-RED 复杂业务流开发及系统备份恢复策略。

**实操内容**：

1. **第三方系统对接**
   - HA REST API / WebSocket 接口调用与鉴权机制（Long-Lived Access Token）
   - MQTT 协议消息发布与订阅（集成 EMQX Broker）
   - Webhook 外部触发配置与数据透传
2. **Node-RED 业务逻辑开发**
   - 安装与配置 Node-RED Add-on
   - 编排复杂分支逻辑、定时轮询与外部系统数据转发
3. **系统可靠性与备份运维**
   - 自动化备份策略配置（本地备份与网络挂载备份）
   - 灾难恢复流程验证与系统迁移演练

**阶段交付**：每组完成 1 套跨系统 API/MQTT 对接流程验证与一份完整的系统备份恢复操作记录。

**能力收获**：

- 掌握 HA 与外部管理系统的数据集成方法
- 能够使用 Node-RED 编排复杂业务流
- 具备独立交付可维护系统与实施灾难备份的能力

### 模块四：方案复盘与交付总结

- 各组项目方案演练与配置评审
- 现场总线稳定性与网络拓扑复盘
- 交付文档与配置归档

## 四、风险与预期管理

### 实施与环境须知

- 本课程聚焦于方案集成与技术实施能力培训，非交钥匙工程。
- 现场改造效果受现场布线条件、设备开放程度与局域网质量影响。
- 本大纲中的安装步骤、接线与实操流程均按标准工程规范设计，正式授课前讲师须按台架规范逐项复核并完成预演。

### 明确不交付范围

- 不替代原有法定消防系统与电梯安全保护系统。
- 不对特定场景的具体节电百分比作绝对承诺。
- 不包含长周期驻场代运维服务。
