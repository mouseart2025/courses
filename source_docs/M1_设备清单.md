## 软件与系统组件

### 核心系统

| 组件 | 版本要求 | 部署方式 | 用途说明 |
| :--- | :--- | :--- | :--- |
| **Home Assistant Container** | 最新稳定版 | 烧录至 reComputer R1125 / R1225 | 边缘中枢与设备管理平台 |
| **ESPHome** | 功能编排 | HA Add-on 插件 | 固件配置、编译与 OTA 管理 |
| **HACS** | 最新版 | 自定义组件 | 社区集成与前端主题扩展 |

### 扩展服务组件

| 插件 / 服务 | 用途说明 |
| :--- | :--- |
| **EMQX / Mosquitto** | MQTT 消息代理中间件，承载多节点异步报文 |
| **Node-RED** | 可视化业务流编排，实现复杂联动与告警逻辑 |

## 现场台架网络拓扑与电气接线

```plaintext
[CUDY AX3000 千兆路由器 (USB-C 供电)]
           │ (局域网有线跳线)
           ▼
    [工业物联网网关 (reComputer R1125 / R1225)] ──(HDMI)──> [便携式现场显示器]
        ├──(RS485 总线)──> XY-MD02 工业温湿度变送器
        ├──(RS485 总线)──> DDSU666 单相智能电表
        └──(Wi-Fi / BLE)──> XIAO ESP32-C6 控制节点群 (灯带控制 / 传感采集)
```
