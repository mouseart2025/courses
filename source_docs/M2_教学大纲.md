# M2 多模态 AI 交互 · 课程大纲

> **多模态 AI 交互** × 空间智能与业务系统集成指南

**课程定位：** 基于 SenseCAP Watcher 硬件、MCP 协议与边缘计算终端，掌握从轻量多模态 Agent 配置、本地业务系统集成到端到端离线语音 AI 管线部署的完整工程实施方法。

## 一、培训目标

完成本课程培训后，学员与团队将具备以下能力：

- **多模态端侧配置能力**：掌握 Watcher 边缘视觉推理、语音交互及大模型 Agent 角色与记忆机制的配置方法。
- **业务系统 MCP 集成能力**：掌握通过 MCP 协议桥接本地 REST API 业务系统（如 WMS / CRM / ERP）的工程链路。
- **自动化工具扩展能力**：掌握配置自动化执行工具（OpenClaw）实现语音触发系统任务的流程。
- **纯本地离线管线搭建能力（L3）**：掌握在 Jetson Orin NX 上部署 VAD、ASR、本地 LLM 与 TTS 完整离线语音管线的方法。

## 二、教学模块

- **硬件台架清点**：按 [M2.2 培训设备清单](M2.2 培训设备清单.md) 确认各工位 reComputer RK3588-40、SenseCAP Watcher（每组 2 台）、路由器、便携显示器及电源线材齐全；L3 班型确认 J4012 算力主机就绪。
- **网络连通性测试**：现场局域网环境与外网大模型 API / SenseCraft AI 平台连通性验证。
- **设备固件预检**：SenseCAP Watcher 完成最新固件更新与 SenseCraft AI 平台账号初始化。
- **主机环境预置**：边缘网关（reComputer RK3588-40）Docker 环境与示例 WMS 镜像预置；J4012 完成 JetPack 与离线语音模型环境预载。
- **教学物料准备**：业务系统条码标贴、实体样本盒与网络拓扑工位分配。

### 模块一：多模态交互能力体验（L1 展示层）

**目标**：理解多模态端侧 AI 的技术架构，体验视觉感知、语音问答、Agent 工具调用与自动化执行的端到端交互链路。

**演示与体验内容**：

1. **端侧轻量视觉推理**
   - Watcher 目标检测模型体验（物料识别、人员靠近、特定动作感知）
   - SenseCraft AI 零代码视觉模型适配流程展示
   - 串口（UART）与网络数据输出格式解析
2. **场景化语音问答与交互**
   - 演示仓储/零售场景下的自然语言实时查询（例如：查询指定货架物料库存、状态播报）
   - 语音输入 → 云端/边缘推理 → 语音合成播报的全链路交互体验
3. **AI 智能体（Agent）机制与 MCP 工具调用**
   - Agent 提示词（Prompt）、角色设定与交互风格配置效果演示
   - 对话记忆机制对比：无记忆、单会话短期记忆与跨会话长期记忆
   - 演示基于 MCP 协议的外部工具（Skill）调用：实时查询仓储数据库
4. **业务系统集成与自动化联动**
   - 智慧仓管全链路演示：语音查库存、物料入库、出库状态更新
   - 桌面自动化工具（OpenClaw）联动演示：语音触发运单查询与设备定时巡检

**阶段交付**：学员完成全流程业务交互体验，理清视觉、语音、Agent 与业务系统的通信逻辑。

**能力收获**：

- 理解边缘视觉与大模型 Agent 结合的技术架构
- 掌握 MCP 协议在端侧 AI 与业务系统对接中的核心作用
- 掌握云端协同与本地部署在不同业务场景下的选型逻辑

### 模块二：业务系统集成与联动配置（L2 顾问层）

**目标**：掌握 Watcher 端侧配置、本地业务系统部署、MCP 桥接及自动化工具联调的全套工程配置方法。

**系统架构与数据链路**：

```plaintext
SenseCAP Watcher（音视频采集 / 终端交互）
    ↓ (Wi-Fi / 外网)
SenseCraft AI 云端平台（大模型意图识别与 Agent 决策）
    ↓ (MCP 协议)
reComputer RK3588-40（本地 MCP 桥接服务）
    ↓ (REST API / 局域网)
本地业务管理系统（Docker 容器运行） + OpenClaw 自动化服务
    ↓
Watcher 语音合成播报 / 屏幕状态反馈
```

**实操步骤**：

1. **视觉 AI 与端侧网络配置（约 30 分钟）**
   - Watcher 联网配置与 SenseCraft 平台绑定
   - 视觉模型选择、置信度与触发阈值参数调优
   - 配置事件上报规则（目标出现、区域检测）
2. **语音 Agent 与角色提示词配置（约 30 分钟）**
   - 在平台中定义 Agent 角色（如：仓管助手、展厅讲解员）
   - 配置角色 System Prompt 与交互风格
   - 记忆模式切换与效果验证
3. **本地业务管理系统部署（约 45 分钟）**
   - 按 [Seeed MCP 外部系统集成指南](https://wiki.seeedstudio.com/mcp_external_system_integration/)，使用 Docker 与 Git 在 RK3588-40 上部署示例 WMS（仓库 [suharvest/warehouse_system](https://github.com/suharvest/warehouse_system)）
   - 访问管理控制台（`http://[设备IP]:2125`），完成管理员初始化与 API Key 生成
   - 导入演示基础物料与库位数据
4. **MCP 桥接服务配置与联调（约 30 分钟）**
   - 获取 Watcher MCP 接入端点与鉴权信息
   - 编辑 `config.yml` 文件，配置本地业务系统的 API 地址与 API Key
   - 启动 MCP Bridge 服务并验证端点握手状态
5. **OpenClaw 自动化任务联动（约 30 分钟）**
   - 部署 OpenClaw 自动化工具环境（参考 [OpenClaw 官方文档](https://docs.openclaw.ai/)）
   - 将自动化脚本注册为 MCP 可调用工具
   - 配置语音指令触发自动化查询与定时任务
6. **全链路整合联调与故障排查（约 30 分钟）**
   - 执行典型业务指令联调（库存查询、入库提交、物流追踪）
   - 常见网络超时、API 鉴权失效与端口冲突排查

**阶段交付**：每组独立完成 1 套包含视觉感知、语音 Agent、本地 WMS 与自动化工具的完整多模态系统联调。

**能力收获**：

- 能够独立配置 Watcher 视觉与语音 Agent 参数
- 掌握基于 Docker 的本地业务系统与 MCP 桥接服务部署
- 掌握基于 MCP 协议扩展新业务 API 的方法
- 具备将该架构迁移适配至展厅、前台等其他业务场景的能力

### 模块三：端到端本地离线语音 AI 管线部署（L3 设计层）

**目标**：在 reComputer J4012（Jetson Orin NX 16GB）上部署并调优全本地运行的语音 AI 管线，实现零公网依赖的离线交互。

**离线架构方案**：

```plaintext
SenseCAP Watcher（音频流输入 / 局域网传输）
    ↓
reComputer J4012 (Jetson Orin NX 16GB)
    ├── VAD (Silero VAD - 语音活动检测)
    ├── ASR (Whisper / FunASR - 本地语音识别)
    ├── LLM (Qwen2.5-7B-Instruct 4-bit 量化 - 本地大语言模型)
    └── TTS (ChatTTS / Piper - 本地语音合成)
    ↓
Watcher 语音播放（纯局域网，无外网依赖）
```

**实操步骤**：

1. **本地管线架构解析（约 30 分钟）**
   - VAD、ASR、LLM、TTS 各模块职责与数据流转时延分析
   - 离线方案与云端方案的指标对比：端到端延迟、并发限制、显存占用与隐私合规
2. **运行环境与依赖准备（约 30 分钟）**
   - 验证 JetPack、CUDA、TensorRT 与 PyTorch 运行环境
   - 克隆离线语音管线项目工程并安装依赖
3. **各模块本地部署与显存调优（约 90 分钟）**
   - 部署 ASR 语音识别模型，配置流式/分段识别
   - 部署量化版本本地 LLM（4-bit AWQ/GGUF），评估 16GB 显存分配
   - 部署轻量高效 TTS 语音合成引擎
   - 将 Watcher 音频流定向至本地服务端口
4. **断网联调与延迟优化（约 30 分钟）**
   - 物理断开外网连接，验证局域网自闭环运行
   - 测试各环节耗时，调优模型上下文长度与采样参数

**阶段交付**：完成 1 套基于 Jetson 独立运行的纯本地多模态语音交互系统，并在断网状态下通过联调测试。

**能力收获**：

- 掌握 VAD → ASR → LLM → TTS 完整本地端到端语音管线架构
- 掌握在 Jetson 边缘计算硬件上进行大模型量化与部署优化的方法
- 具备在强隐私与工业隔离网环境下交付 AI 交互方案的能力

## 四、风险与预期管理

### 环境与硬件须知

- L1/L2 云端协同方案要求现场具备稳定上行互联网带宽。
- L3 纯本地方案依赖 100 TOPS 级别边缘 GPU 硬件（Jetson Orin NX 16GB 及以上）。
- 语音识别准确率受现场环境底噪、方言口音及专业行业词库影响。

### 明确不交付范围

- 不替代高并发、长链路的专用人工客服系统。
- 不承诺对模糊主观多轮逻辑的 100% 准确推理。
- 不包含对客户未开放 API 的封闭旧系统的反向破解开发。
