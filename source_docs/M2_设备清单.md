## 部署方案架构对比

| 部署形态 | 网络环境依赖 | 核心硬件组合 | 典型适用场景 |
| :--- | :--- | :--- | :--- |
| **L1 展示方案** | 需互联网接入 | Watcher + Wi-Fi 路由器 | 展厅演示、概念验证、快速交互体验 |
| **L2 顾问方案** | 需互联网接入 | Watcher + RK3588-40 网关 + 路由器 | 中小企业业务集成、智慧仓管、前台自动化 |
| **L3 设计方案** | 纯局域网（零公网） | Watcher + J4012 (Orin NX) + 路由器 | 工业隔离区、政企高隐私、防爆与离网现场 |

## 部署要点

1. **外网依赖**：L1/L2 云端协同方案要求现场具备稳定上行互联网带宽，用于 SenseCraft AI 平台与大模型服务调用。
2. **Watcher 预配置**：课前完成 Watcher 固件更新、SenseCraft AI 平台账号初始化与设备配网，避免课堂时间浪费。
3. **RK3588-40 环境预置**：提前安装 Docker、拉取示例 WMS 容器镜像并验证 `http://[设备IP]:2125` 管理控制台可访问。
4. **MCP Bridge 配置**：编辑 `config.yml` 填入本地业务系统 API 地址与 API Key，验证端点握手状态。
5. **OpenClaw 联调**：部署前按官方文档复核 OpenClaw 自动化工具与 MCP 扩展注册流程。
6. **L3 离线算力环境**：reComputer J4012 需预置 JetPack、CUDA、TensorRT 与 PyTorch 运行环境。
7. **离线语音管线**：调优 VAD → ASR → LLM → TTS 各模块在 Jetson 上的端到端延迟、并发限制与显存占用。
8. **断网验证**：L3 交付须物理断开外网连接，验证局域网自闭环运行与端到端语音交互可用性。
