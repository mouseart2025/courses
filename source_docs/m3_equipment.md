## 部署要点

1. **频段一致性**：所有 LoRa 设备必须使用同一频段（433/868/915 MHz），混用频段将导致物理层无法解调组网。
2. **天线匹配与极化**：检查天线频段标识与设备一致，Solar Node 部署时注意天线垂直极化方向与架设高度。
3. **信道加密**：为每个培训组分配独立的主信道名称与 256 位 AES 预共享密钥（PSK），避免不同小组间信号互相串扰。
4. **节点角色配置**：根据现场拓扑合理设置 Client / Repeater / Router 角色，避免广播风暴与空中信道拥塞。
5. **MQTT 桥接参数**：ESP32S3 网关接入 MQTT Broker 时，建议切换为现场自建局域网 EMQX Broker，保障完全离网可用。
6. **报文格式解析**：Meshtastic 固件默认通过 Protobuf 输出，JSON 输出需另行配置；Node-RED 解析流需与配置相匹配。
7. **时延与跳数管理**：消息时延随中继跳数增加而累加（典型环境为 1–3 秒/跳），复杂遮挡环境下需预留合理跳数预算。
8. **L3 开发环境**：PlatformIO 编译 Meshtastic 源码时目标板型为 `seeed_wio_tracker_L1`，需提前克隆官方仓库并配置 PlatformIO 编译链。
