## 部署要点

1. **reCamera 预检**：课前检查固件版本、网络连通性、Node-RED 与 SSCMA 插件状态，并验证 RTSP 554 端口输出稳定。
2. **Jetson 系统环境**：reServer J4012 需刷写 JetPack 镜像并配置 Docker `--runtime nvidia`，Frigate 使用 TensorRT 量化加速。
3. **PoE 与网络规划**：为每台摄像头与边缘主机分配静态 IP，PoE 交换机需支持 802.3af/at 标准。
4. **RTSP 接入格式**：摄像头 RTSP 地址示例 `rtsp://admin:admin@<ip>:554/live`，检测帧率建议 5–10 FPS，兼顾实时性与算力负载。
5. **检测区域调优**：在 Frigate 中定义 Zones 与 Masks，排除树枝晃动、反光与背景干扰杂物，降低误报率。
6. **置信度阈值管理**：根据现场光照、安装高度与遮挡情况调整 Min Score / Threshold，记录调优前后数据对比。
7. **L3 模型训练**：标准流程为标注数据 → YOLO 训练 → ONNX 导出 → TensorRT Engine（Jetson）/ cvimodel（reCamera）模型转换。
8. **合规红线**：严禁人脸身份识别与生物特征追踪，项目交付前须与客户书面确认为一般物体/安全合规检测边界。
